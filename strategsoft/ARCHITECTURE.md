# Strategsoft — план файлов и схема данных

## Что удалось изучить

Доступен один табличный файл: `Копия Weekmark [Classic]. Трекер задач .xlsx`.

Листы:

| Лист | Назначение | Пользовательские поля | Не импортировать |
| --- | --- | --- | --- |
| Старт | инструкция | нет данных | служебный текст |
| Итоги | сводка недель по имени листа = дате | A6+ даты начала | формулы INDIRECT, графики |
| 2026-09-07 / 2026-09-14 | экземпляры недель | B4 дата, B8 цель, главные и обычные задачи, отметки, привычки, рефлексия | колонки T+ (служебный расчёт) |
| Доп. задачи | бэклог | задача, срок, важность, отметка | статус по формуле |
| Настройки | категории и привычки | название категории, цвет, привычка, цель 1–7 | пустые служебные |
| Шаблон | пустая неделя | как у недели, без даты | формулы |

Неделя считается с понедельника (`WEEKDAY(..., 2)`). Главных дел — до трёх в день (первые три строки дня). Новая неделя в таблице создавалась дублированием шаблона; в приложении это отдельная запись архива.

Таблицы Finmark / Habitmark / Moodmark / Lifemark **в папке нет**. Импорт этих источников помечен как «ожидает исходный файл». PDF использованы как методики, тексты переписаны для интерфейса и не копируют исходные бренды.

## Слои

```
src/types        — TypeScript-модель
src/data         — репозиторий (локальный JSON, интерфейс под сервер)
src/services     — расчёты: недели, привычки, состояние, цели, финансы
src/content      — руководства
src/ui           — тема и общие компоненты
app/             — экраны Expo Router
```

## Хранение v1

Локальный JSON в AsyncStorage (`strategsoft.db.v1`). Все даты календарные — `YYYY-MM-DD` в локальной зоне устройства. ISO-метки `createdAt` / `updatedAt` — UTC.

Позже тот же `AppRepository` можно подключить к API:

- **Рекомендуемый backend:** Supabase (Postgres + RLS) или FastAPI + PostgreSQL.
- **Авторизация:** OAuth (Apple / Google) + email magic link. Сессии только на устройстве, секреты API не класть в клиент.
- Синхронизация: `pull/push` по `updatedAt`, конфликт — «последняя запись пользователя».

## Запуск

```bash
cd strategsoft
npm install
npx expo start
```

Затем Expo Go (SDK 58) или эмулятор Android / симулятор iOS.
