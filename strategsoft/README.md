# Strategsoft

Мобильное приложение для iOS и Android: сегодня, недельный план, привычки, состояние, цели, финансы и руководства.

Данные хранятся локально на устройстве. Секреты и ключи API в клиент не входят.

## Открыть в браузере

В PowerShell:

```powershell
cd "c:\Users\god20\Downloads\Сайт\Prilogenie_strategsoft\strategsoft"
.\start-web.ps1
```

Или вручную:

```powershell
cd "c:\Users\god20\Downloads\Сайт\Prilogenie_strategsoft\strategsoft"
npx expo start --web --port 8081
```

Браузер должен открыть **http://localhost:8081**. Если страница не открылась сама, вставьте адрес вручную.

Первый запуск ставит зависимости (`npm install`) — это нормально и занимает несколько минут. Не запускайте несколько `npm install` одновременно: из‑за этого компьютер может зависнуть.

## Телефон и эмулятор

```powershell
npx expo start
```

Дальше: Expo Go, эмулятор Android или симулятор iOS.
